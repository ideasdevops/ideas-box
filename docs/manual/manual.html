1Qué es Ideas Box

Un puesto de trabajo completo para operar una empresa con agentes de IA, instalable en una máquina recién formateada.

Ideas Box no es un programa con ventanas. Es la organización que hace que trabajar con agentes de IA rinda: una estructura de datos, un equipo de agentes con roles definidos, procedimientos escritos, memoria que sobrevive a la sesión y conexiones a las herramientas que ya usás.

Qué instala

CapaQué es
Base técnicaNode, Python, ffmpeg, git y Claude Code
Raíz de datosUn disco, un volumen o una carpeta con la estructura de tu empresa
16 agentesDirección, desarrollo, operaciones, QA, ventas, marketing, contenido y clientes — con el nombre de tu empresa
~20 procedimientosCómo se resuelve un bug, cómo se arma una propuesta, cómo se registra una operación
Packs de skillsMarketing, diseño y disciplina de código, de repositorios abiertos
17 conectoresBúsqueda web, bandeja de atención, servidores, redes sociales, video, código
ReglasQué puede hacer un agente solo y qué necesita tu aprobación

Qué no hace

  • No toca tus discos. No reparticiona ni formatea nada. Si querés un disco dedicado, te dice cómo crearlo y después lo usa.
  • No guarda contraseñas en la configuración de Claude. Cada conector arranca por un lanzador que lee su archivo de credenciales, con permisos restringidos.
  • No trae datos de nadie. Los agentes son plantillas que se completan con los datos de tu empresa durante la instalación.
  • No publica ni despliega solo. Toda acción hacia afuera pide tu aprobación.
La idea de fondo

Un agente sin reglas es un becario con acceso a producción. Ideas Box empaqueta las reglas, no solamente las herramientas: por eso lo primero que vas a leer en cada agente es qué no puede hacer sin preguntarte.

Cuánto tarda

Entre 10 y 25 minutos según cuántos conectores actives. La mayor parte es descarga y compilación: podés dejarlo corriendo y volver.

Decidí dónde van a vivir los datos

Es la única decisión difícil de cambiar después. Tres opciones, de más a menos recomendable:

  1. Un disco o volumen aparte. Reinstalás el sistema operativo sin perder nada, y te llevás la empresa entera enchufando el disco en otra máquina. Montalo antes de instalar para que aparezca en la lista.
  2. Una partición o volumen APFS dedicado en el disco interno. Mismo beneficio, sin hardware extra.
  3. Una carpeta en tu home. Funciona perfecto y es lo que elige la mayoría al arrancar. Se puede mudar después.

3Instalación en Linux

Ubuntu, Linux Mint y Debian. Cuatro pasos desde una máquina recién instalada.

1

Instalar git

Una instalación limpia de Ubuntu o Debian no lo trae, y sin git no podés bajar Ideas Box.

sudo apt update && sudo apt install -y git
2

Bajar Ideas Box

git clone https://github.com/ideasdevops/ideas-box.git
cd ideas-box
3

Ejecutar el asistente

bash install.sh

Te pide la contraseña de sudo en el primer paso, para instalar los paquetes del sistema. De ahí en adelante son preguntas sobre tu empresa y tus herramientas (sección 5). Si primero querés ver qué haría sin que toque nada: bash install.sh --dry-run.

4

Autenticar Claude Code

Esto no lo puede hacer el asistente por vos: abre el navegador para que inicies sesión.

claude

Opciones útiles

OpciónPara qué
--dry-runMostrar las acciones sin ejecutarlas
--data-root RUTAFijar la raíz de datos y saltar esa pregunta
--empresa "NOMBRE"Fijar el nombre y saltar esa pregunta
--skip-depsNo instalar paquetes del sistema (si ya los tenés)

Usá bash install.sh. El asistente es interactivo y necesita una terminal real; si lo invocás con curl … | bash no puede leer tus respuestas y corta con un aviso en vez de instalar algo a medias.

4Instalación en macOS

Intel y Apple Silicon, de macOS 12 en adelante.

1

Herramientas de línea de comandos de Xcode

Traen git y el compilador. Si nunca las instalaste, se abre un instalador gráfico de Apple: aceptalo y esperá a que termine.

xcode-select --install
2

Bajar Ideas Box

git clone https://github.com/ideasdevops/ideas-box.git
cd ideas-box
3

Ejecutar el asistente

bash install.sh

macOS no trae gestor de paquetes. Si no tenés Homebrew, el asistente te ofrece instalarlo; aceptá y dejalo trabajar — la primera vez tarda varios minutos.

Tres diferencias respecto de Linux

TemaEn macOS
PaquetesHomebrew en lugar de apt. Si al terminar la instalación de Homebrew la terminal dice «command not found: brew», abrí una ventana nueva y repetí

El código está escrito para las utilidades y el bash que trae el sistema, pero todavía no fue probado en hardware Apple real. Si algo falla, el error y el paso donde ocurrió son información valiosa: reportalos (sección 13) y lo corregimos.

5El asistente, paso por paso

Ocho etapas. Qué hace cada una, qué te pregunta y qué conviene responder.

1 · Dependencias del sistema

Instala paquetes base, Node, Claude Code y, si querés, ffmpeg e ImageMagick para los agentes de contenido. Pregunta si instalar Docker: respondé que no salvo que vayas a levantar servicios en esta máquina.

2 · Identidad de la empresa

Nombre, identificador corto, rubro, sitio, responsable, idioma y zona horaria. Todo esto se escribe en los agentes y en la documentación. Queda guardado en un archivo de texto editable: si te equivocás, se corrige después con ideasbox profile.

3 · Raíz de datos

Te muestra los discos y volúmenes montados y te deja elegir, o crear una carpeta en tu home. Si elegís la opción «quiero un disco dedicado y todavía no lo tengo», te imprime el procedimiento exacto para tu sistema y podés seguir con una carpeta mientras tanto.

4 · Packs de skills

Descarga colecciones de procedimientos de repositorios abiertos: disciplina de código y redacción (siempre), marketing y criterio de diseño (recomendados) y dos opcionales más pesados.

5 · Conectores

Instala primero los tres del núcleo, que no piden credenciales. Después te ofrece uno por uno los de negocio. Para cada uno que aceptes te va a pedir sus credenciales y, si admite varias cuentas —como Chatwoot, Easypanel o las redes sociales—, te deja agregar tantas como tengas, cada una con su etiqueta.

La etiqueta importa

Cuando cargás dos servidores, quedan como easypanel-produccion y easypanel-clientes. Esa etiqueta es lo único que distingue un servidor de otro cuando un agente va a reiniciar un servicio: poné nombres que no se presten a confusión.

6 y 7 · Agentes y runtime

Se generan los 16 agentes con los datos de tu empresa, los procedimientos, la documentación y el índice de memoria, y se enlazan al runtime de Claude Code. Cada agente recibe solamente las herramientas de los conectores que instalaste: si mañana agregás uno, los agentes que lo usan se actualizan solos.

8 · Permisos y hook de arranque

Permisos de Claude Code (lectura libre; escritura y acciones sensibles bajo aprobación), bloqueo de lectura sobre tus credenciales y claves SSH, y un aviso de arranque que detecta si el disco de datos no está montado.

Volver a correrlo es seguro

El asistente es idempotente: si lo ejecutás de nuevo, actualiza en lugar de duplicar. Y nunca pisa un archivo que hayas editado vos — deja la versión nueva al lado, con extensión .nuevo, y te avisa.

6Los primeros 30 minutos

Terminó la instalación. Esto es lo que conviene hacer antes de pedirle trabajo a un agente.

1

Verificar que quedó sano

ideasbox doctor

Revisa perfil, disco de datos, árbol de agentes, enlaces, Claude Code y cada conector. Tiene que terminar con Stack sano. Para que además pruebe de verdad cada conector, arrancándolo como lo hace Claude:

ideasbox doctor --deep
2

Abrir Claude Code y conocer el equipo

claude

Probá con: «mostrame qué agentes tengo y qué hace cada uno».

3

Cargar el contexto de tu empresa

Los agentes ya saben cómo trabajar, pero todavía no saben nada de tu negocio. Dedicale la primera sesión a eso. Ejemplos de lo que conviene decirle:

  • «Guardá en memoria que mi empresa hace X, le vende a Y, y su diferencial es Z»
  • «Creá la carpeta del cliente Fulano y anotá lo que sabemos: contacto, qué le vendimos, en qué estado está»
  • «Anotá que los martes cierro pedidos a las 18 y que no trabajo con transferencias»
  • «Registrá que el servidor de producción es el que tiene la etiqueta produccion»

Cada cosa que cargues es una cosa que no vas a tener que repetir nunca más.

4

Pedir el primer trabajo real

Los agentes se invocan por nombre:

  • «Usá sales-crm para preparar una propuesta para Fulano»
  • «Que ops-support revise cómo está el servidor de producción»
  • «content-strategist, armame el calendario de contenido del mes»

Si no sabés cuál corresponde, pedíselo a agents-orchestrator: reparte el trabajo entre las áreas y evita que dos agentes hagan lo mismo.

Las cuatro fronteras que evitan desastres

  • Marketing define, contenido produce. Nunca el mismo objetivo a los dos en paralelo.
  • Un solo dueño del envío. Solo comms-chatwoot le escribe a una persona; los demás preparan el mensaje. Así nadie recibe dos respuestas distintas.
  • Nadie despliega solo. dev-saas prepara y verifica, el disparo es tuyo.
  • Toda acción irreversible se aprueba de a una. Aprobar hoy no habilita mañana.
Son archivos de texto

Cada agente es un archivo en .claude/agents/ dentro de tu raíz de datos. Si uno no trabaja como querés, editalo: es la forma esperada de usar Ideas Box, no un atajo. Después corré ideasbox sync.

Dónde quedan tus credenciales

En ~/.config/ideasbox/secrets/, un archivo por conector, con permisos que solo permiten leerlas a tu usuario. No se escriben en la configuración de Claude: cada conector arranca por un lanzador que las carga en el momento. ideasbox doctor avisa si alguna se filtró donde no corresponde.

Dos reglas de esta estructura

  • La fuente de verdad está acá, no en tu home. Lo que hay en ~/.claude son enlaces a esta carpeta. Por eso podés reinstalar el sistema operativo sin perder nada.
  • Cada cliente y cada prospecto tiene su propia carpeta en 02-CLIENTES. Los agentes tienen prohibido entrar a la carpeta de un cliente que no sea el de la tarea.

Respaldo

ideasbox backup

Genera un comprimido en 05-OPERACIONES/backups/stack/ con agentes, memoria, documentación y configuración. Incluye tus credenciales: guardalo cifrado y no lo subas a ningún lado sin protegerlo.

Si el disco de datos no está montado

Claude te lo avisa apenas abrís una sesión, antes de que un agente empiece a trabajar a ciegas y concluya que tu información «no existe». Si ves ese aviso: montá el disco y volvé a abrir.

11Reglas de seguridad

Lo que Ideas Box no deja que pase, y lo que depende de vos.

Siempre te van a pedir aprobación

  1. Escribirle a un cliente o prospecto
  2. Publicar, programar o responder en redes sociales
  3. Gastar dinero: pauta, APIs pagas, servicios nuevos
  4. Reiniciar, detener, desplegar o borrar un servicio
  5. Ejecutar comandos en un servidor remoto
  6. Modificar o borrar datos de producción
  7. Cualquier acción difícil de revertir

Aprobar una vez no habilita la próxima. Es deliberado: la mayoría de los incidentes graves con agentes vienen de una autorización que alguien dio una vez y quedó abierta.

Credenciales

  • Viven en ~/.config/ideasbox/secrets/, un archivo por conector, legible solo por tu usuario.
  • No se copian a la memoria, ni a las bitácoras, ni a las capturas de pantalla.
  • Los agentes tienen bloqueada por configuración la lectura de esa carpeta, de tus claves SSH y de cualquier archivo .env.

Borrar es la acción más cara

Muchos borrados de paneles y aplicaciones no son reversibles y se llevan puestos datos asociados: una bandeja borrada puede llevarse miles de conversaciones con sus adjuntos. Los agentes no tienen herramientas de borrado declaradas y tienen instrucción explícita de preguntar ante la duda.

Datos de clientes

Si administrás infraestructura de terceros, vas a ver credenciales de tus clientes en sus paneles. Mirarlas para diagnosticar está permitido; usarlas para leer o escribir en sus sistemas, no. Es una regla escrita en los agentes de operaciones y desarrollo.

Lo que depende de vos

Ideas Box te protege de los accidentes, no de las decisiones. Si aprobás un envío masivo mal armado, se envía. Leé lo que el agente te muestra antes de decir que sí: siempre te muestra el texto exacto y el destinatario antes de ejecutar.

Cómo leer un diagnóstico

ideasbox doctor

✓ Perfil: Panadería Los Tres Hornos (tres-hornos)
✓ Raíz de datos montada: /mnt/datos/tres-hornos (libre: 234G)
✓ Runtime: 16 agentes y 363 skills enlazados
! MCP brave-search: hay credenciales vacías        ← advertencia: se puede usar igual
✗ MCP easypanel-prod: falta el lanzador            ← problema: ese conector no funciona

✓ está bien · ! funciona pero algo falta · ✗ eso no anda. Las advertencias no impiden trabajar; los problemas sí, pero solo afectan al conector que mencionan.

13Soporte

Dónde seguir, cómo reportar y qué esperar.

El repositorio

github.com/ideasdevops/ideas-box — código, catálogo de conectores y documentación técnica. Licencia MIT: usalo, modificalo y vendé servicios sobre él.

Ojo con las licencias de terceros

MIT cubre Ideas Box, no lo que instala. Los packs de skills y los conectores se descargan de sus repositorios originales, cada uno con su propia licencia, que puede no ser MIT. docs/TERCEROS.md lista el origen de cada uno: revisalo antes de usarlos comercialmente.

Si algo falla, qué mandar

Con estas cuatro cosas el problema se resuelve en una vuelta en vez de tres:

  1. Sistema y versión: la salida de uname -a y de lsb_release -a o sw_vers
  2. En qué paso del asistente falló (de los ocho de la sección 5)
  3. El error completo, copiado tal cual, no una captura recortada
  4. La salida de ideasbox doctor

Antes de mandar nada, revisá que no haya credenciales en el texto. Los tokens aparecen en los mensajes de error más seguido de lo que uno espera.

Ideas Box te deja el puesto armado. Lo que sigue —adaptar los agentes a tu operación, conectar tus sistemas, poner los procedimientos de tu negocio por escrito— es donde aparece el rendimiento real. Si querés acompañamiento en esa etapa, IdeasDevOps lo hace como servicio.

Una última cosa

Todo lo que genera Ideas Box es texto plano: agentes, procedimientos, memoria, documentación. No hay base de datos propietaria ni formato cerrado. Podés leerlo, editarlo, versionarlo con git y llevártelo. Es tuyo.
